# 🎯 VALORANT Store & Skin Inspector (ระบบดูร้านค้าและสกินวาโรแรนต์)

เว็บแอปพลิเคชันสำหรับตรวจดูร้านค้าประจำวัน (Daily Offers), ไนท์มาร์เก็ต (Night Market), เซ็ตบันเดิล (Featured Bundles) และยอดเงิน (VP, Radianite, Kingdom Credits) พร้อมระบบดูสี (Chromas) และวิดีโออนิเมชัน/เอฟเฟกต์/Finisher ของปืนครบครัน

---

## 🛡️ มาตรการความปลอดภัยและป้องกันรหัสผ่านหลุด (Zero-Leak Security)
1. **แยกไอดีอิสระ 100% (Isolated Multi-User Sessions)**:
   - ใช้ Session Cookie แบบสุ่มและเข้ารหัส (Cryptographically Secure UUID)
   - ผู้ใช้งานแต่ละคนจะมีกล่องข้อมูลแยกจากกันโดยสิ้นเชิง ไม่มีการปนข้อมูลกัน
2. **ไม่บันทึกรหัสผ่านลงดิสก์หรือฐานข้อมูล (Zero Disk Footprint)**:
   - รหัสผ่านจะถูกส่งผ่านช่องทางเข้ารหัส TLS ตรงไปยัง Riot Games เพื่อขอรับ Token และทำลายทิ้งทันที
3. **รองรับ 2FA (Two-Factor Authentication)**:
   - รองรับรหัส OTP ทางอีเมลและ Google/Riot Authenticator
4. **รองรับการล็อกอินผ่าน Google / Social / Riot Token**:
   - สำหรับผู้เล่นที่เชื่อมต่อผ่าน Google, Apple, Facebook, Xbox หรือ PSN มีระบบ Token Auth ให้ใช้งานได้โดยไม่ต้องกรอกรหัสผ่าน

---

## 🚀 วิธีเปิดใช้งาน

```bash
cd ~/val-shop-checker
./start.sh
```

หรือสั่งรันโดยตรง:
```bash
node server.js
```

เมื่อระบบเริ่มทำงานแล้ว ให้เปิดเบราว์เซอร์ไปที่:
- **บนอุปกรณ์นี้:** `http://localhost:3000`
- **ให้เพื่อนหรือคนอื่นในวง WiFi เดียวกันเข้าใช้งาน:** `http://<IP_เครื่องของคุณ>:3000`

## ✨ ฟีเจอร์หลัก (Features)
- 🏷️ **ระบบเปรียบเทียบราคาเงินในเกมกับเงินจริง (VP Store Comparator)**:
  - เปรียบเทียบราคาเงินจริง (บาท THB) ระหว่าง **Riot Games Official (ในเกม), Codashop TH, UniPin TH, Razer Gold, SEAGM (PINs), และร้านเติมเกมชั้นนำ**
  - คำนวณแพ็กเกจที่ถูกที่สุดอัตโนมัติ (Smart Top-Up Optimizer) พร้อมบอกจำนวนเงินที่ประหยัดได้ (฿ และ %)
  - หักลบ VP ที่มีอยู่ในกระเป๋าจริงในไอดี เพื่อคำนวณเฉพาะส่วนที่ต้องเติมเพิ่ม
  - ตารางเปรียบเทียบทุกแพ็กเกจ (Price Matrix) ไฮไลท์ร้านที่ถูกที่สุดในแต่ละระดับ
  - เครื่องมือวิเคราะห์ความคุ้มค่าของร้านค้าอื่น / เพจร้านค้า (Custom Shop Tester)
  - ปุ่มเปรียบเทียบราคาเงินจริงในทุกสกินของร้านค้ารายวัน, ไนท์มาร์เก็ต และ Wishlist
- 🛒🛒 **ร้านค้า 4 สกินประจำวัน (Daily 4 Skins)** พร้อมเวลานับถอยหลังรีเซ็ตร้านค้า
- 🌙 **ตลาดกาลกิณี (Night Market)** แสดงส่วนลด % และราคาที่ลดแล้ว
- 🎁 **Featured Bundles** แสดงรายละเอียดของแถมและราคาบันเดิล
- 🎨 **ดูสีปืนครบทุก Chroma** คลิกสลับสีและแสดงภาพเรนเดอร์แบบ Real-time
- 🎬 **ดูเอฟเฟกต์วิดีโอ / เสียง / รีโหลด / Finisher** สตรีมตรงจาก Riot Games
- 💰 **แสดงยอดคงเหลือ:** VP, Radianite Points (RP), Kingdom Credits (KC)
- 👤 **แสดงชื่อในเกม, แท็ก (GameName#TAG), เลเวล และ Region**
