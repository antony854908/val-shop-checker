## 🌟 ฟีเจอร์หลัก (Features)

### 🛒 1. ร้านค้าประจำวัน & ไนท์มาร์เก็ต (Daily Offers & Night Market)
- **Daily 4 Skins:** ตรวจสอบ 4 สกินประจำวันพร้อมเวลานับถอยหลังรีเซ็ตร้านค้าแบบ Real-time
- **Night Market:** ตรวจสอบตลาดกาลกิณี คำนวณเปอร์เซ็นต์ส่วนลดและราคาลดพิเศษอัตโนมัติ
- **Featured Bundles:** ดูรายละเอียดเซ็ตบันเดิลปัจจุบัน พร้อมคำนวณราคาหักลดสำหรับไอเทมที่มีอยู่แล้ว
- **Live Wallet:** แสดงยอดคงเหลือ VP (Valorant Points), RP (Radianite Points) และ KC (Kingdom Credits)

### 🎬 2. ระบบตรวจสกินปืน & Finisher Video HD (Skin Inspector)
- **สลับดูสีปืน (Chromas):** ดูภาพเรนเดอร์สกินครบทุกสี แบบ High Definition
- **วิดีโออนิเมชัน & เสียงปืน:** สตรีมวิดีโอการยิง, รีโหลด, อัปเกรด VFX และ Finisher ปิดฉากตรงจาก Riot Games CDN
- **คลังสกินครบครัน 1,380+ ชิ้น:** ค้นหาสกินปืน, มีด, ปืนพก, การ์ด, สเปรย์, ฉายา และบัดดี้ได้ทั้งหมด

### 🤖 3. โมเดลตัวละคร 3D & โค้ชวิเคราะห์การเล่น (3D Agent Inspector & Tactical Coach)
- **3D Agent Stage:** สำรวจโมเดลตัวละคร 3D หมุนและดูรายละเอียดแบบรอบทิศทาง
- **Tactical Guide & Abilities:** เจาะลึกข้อมูลสกิล, บทบาท (Duelist, Initiator, Controller, Sentinel) และแนวทางการเล่น
- **AI Playstyle Coach:** ระบบแนะนำ Agent ที่เหมาะสมกับสไตล์การเล่นของผู้ใช้ พร้อมวิเคราะห์จุดเด่นและคอมโบสกิล

### 📊 4. สถิติและประวัติการเล่น (Career & Match Analytics)
- **Player Stats:** แสดงเลเวลไอดี, แท็กกิลด์/ชื่อในเกม, Region (AP/NA/EU/KR/LATAM/BR)
- **Match History:** ดูสถิติการเล่นย้อนหลัง อัตราการยิงหัว (Headshot %), KDA, ผลแพ้ชนะ และประวัติคะแนน MMR

### 💎 5. ระบบเปรียบเทียบราคาเงินจริง (OverTopup VP Optimizer)
- **Live OverTopup Sync:** เชื่อมต่อและดึงราคาแพ็กเกจเติมเงินแบบ Real-time
- **Smart Wallet Deduction:** หักลบ VP ที่มีอยู่ในกระเป๋าอัตโนมัติ คำนวณเฉพาะจำนวนที่ต้องเติมเพิ่ม
- **Smart Package Optimizer:** คำนวณหาคู่แพ็กเกจที่ประหยัดเงินบาท (THB) มากที่สุด และแสดงจำนวนเงินที่ประหยัดได้
- **Direct Top-Up Flow:** ลิงก์ตรงสำหรับเติมเงินผ่าน Riot ID บน OverTopup ปลอดภัย ไม่ต้องกรอกรหัสผ่าน

### ⭐ 6. ระบบบันทึกสกินที่อยากได้ (Wishlist Alert)
- บันทึกสกินที่ชื่นชอบลงใน Wishlist ส่วนตัว
- ไฮไลต์ป้ายเตือนทันทีเมื่อสกินใน Wishlist ปรากฏขึ้นในร้านค้ารายวัน

### 🔊 7. ระบบเสียง Tactical Audio Engine
- เอฟเฟกต์เสียง Mechanical Red Switch (Clean Thock)
- ระบบเสียงแจ้งเตือนแบบ Sci-Fi UI, Holographic Inspection SFX และเสียงคลิกสมจริงตามระดับความเร็ว

## 🔐 ระบบความปลอดภัยระดับสูง (Zero-Leak Security)

| มาตรการความปลอดภัย | รายละเอียดการทำงาน |
| :--- | :--- |
| **🛡️ Zero Disk Footprint** | ไม่มีการบันทึกรหัสผ่านหรือข้อมูลส่วนตัวลงฐานข้อมูลหรือฮาร์ดดิสก์ |
| **🔑 Official Riot OAuth Flow** | รองรับการเข้าสู่ระบบทางการผ่าน Google, Apple, Facebook, Xbox และ Riot Token โดยไม่ต้องกรอกรหัสผ่าน |
| **🔒 AES-256-GCM Session Storage** | ข้อมูล Session จัดเก็บด้วยการเข้ารหัสลับมาตรฐาน Authenticated Encryption พร้อม Salted IV |
| **⚡ Multi-User Isolation** | ผู้ใช้งานทุกคนแยก Session UUID แบบ Cryptographically Secure ออกจากกันอย่างเด็ดขาด |
| **🚫 Anti-Brute-Force Rate Limiting** | จำกัดความถี่คำขอเพื่อป้องกันการโจมตีและการสุ่มรหัสผ่าน (HTTP 429 Protection) |
| **🛡️ Security Headers & Strict CSP** | ติดตั้ง Helmet, X-Frame-Options (`DENY`), X-Content-Type-Options และ Strict Content Security Policy |

## 🚀 วิธีเปิดใช้งาน (Quick Start)

### 🪟 สำหรับ Windows (คลิกเดียวรัน)
1. ดับเบิ้ลคลิกไฟล์ `start.bat` ในโฟลเดอร์โปรเจกต์
2. โปรแกรมจะตรวจสอบ dependencies และเปิดหน้าเว็บ `http://localhost:3000` ให้อัตโนมัติ

### 📱 สำหรับ Android (Termux)
```bash
cd ~/val-shop-checker
./start.sh
```

### 💻 สำหรับ macOS / Linux
```bash
# 1. ติดตั้ง dependencies
npm install

# 2. เริ่มต้นรันเซิร์ฟเวอร์
npm start
```

เปิดเบราว์เซอร์แล้วเข้าสู่: **`http://localhost:3000`**

## 🌐 การ Deploy บน Vercel (Serverless)

โปรเจกต์นี้ได้รับการตั้งค่าพร้อมสำหรับการ Deploy บน **Vercel** ทันที:
1. เชื่อมต่อ GitHub Repository เข้ากับ Vercel
2. ตัวโปรเจกต์มีไฟล์ `vercel.json` และ `api/index.js` จัดเตรียมไว้แล้ว
3. ระบบรองรับ `X-Val-Auth-Pack` Client-Side Rehydration ทำให้การล็อกอินคงอยู่ต่อเนื่อง 30 วันแม้บนสถาปัตยกรรม Serverless
